# CV Web - Johan Eliu Salgado

Hoja de vida (CV) web personal desarrollada como proyecto para la materia
**Programación en Ambiente Web I** — Unidad Central del Valle del Cauca (UCEVA).

## Descripción

Página web que presenta el perfil profesional de un desarrollador web front-end,
construida con **HTML5**, **CSS3** y el framework **PicoCSS**.

## Tecnologías utilizadas

- HTML5 (etiquetas semánticas: `header`, `nav`, `main`, `section`, `article`, `footer`)
- CSS3 (selectores de etiqueta, clase, ID, descendientes; diseño responsive con media queries)
- [PicoCSS](https://picocss.com/) (framework CSS vía CDN)

## Contenido de la página

- Información personal
- Perfil profesional
- Formación académica
- Experiencia
- Habilidades (tabla)
- Proyectos
- Cursos y certificaciones
- Contacto (formulario)
